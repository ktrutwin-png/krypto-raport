# Trading tools we use — erl.grey83 / Hexa

Free, open-source repos behind our trading bots and research.
You asked for it with **TRADE** in the comments — here it is. Share it freely.

> Education only, not financial advice. Bots lose too. Test everything on a demo account first.

## ✅ In daily use

| Repo | What it does for us |
|---|---|
| [freqtrade/freqtrade](https://github.com/freqtrade/freqtrade) | Crypto trading bot (with FreqAI) — runs our crypto strategies |
| [Jakeschincariol/day-trader-skill](https://github.com/Jakeschincariol/day-trader-skill) | 11 day-trading skills for Claude — how we read the market and plan entries |
| [TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents) | Team of AI analysts (news, technicals, risk) — research only |
| [basicmachines-co/basic-memory](https://github.com/basicmachines-co/basic-memory) | Shared memory for our AI agents |
| [MetaTrader5 (Python)](https://pypi.org/project/MetaTrader5/) | Official MT5 package — our gold & silver bots run on it |
